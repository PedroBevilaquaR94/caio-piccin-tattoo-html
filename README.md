# Caio Piccin Tattoo — versão estática

Esta é a versão do site construída somente com **HTML, CSS e JavaScript**. Não há dependências, processo de compilação ou servidor de aplicação obrigatório.

## Como abrir

Abra o arquivo `index.html` diretamente em um navegador ou publique a pasta em qualquer hospedagem estática, como GitHub Pages, Netlify ou Cloudflare Pages.

## Estrutura

| Arquivo | Função |
|---|---|
| `index.html` | Estrutura e conteúdo da página. |
| `styles.css` | Identidade visual Ink Rubi Premium e responsividade. |
| `script.js` | Carrosséis, menu móvel e envio do formulário para WhatsApp. |
| `assets/` | Fotos originais utilizadas no hero e no portfólio. |
